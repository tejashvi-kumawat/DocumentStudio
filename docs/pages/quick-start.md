# Quick start

1. **Install** the app for your OS ([Install](#/install)).
2. **Open** Document Studio from the app menu (or `document-studio` / `document_studio` in a terminal).
3. **Open a PDF** (or drop files onto the window).
4. Pick a tool — merge, compress, protect, OCR, and more.
5. **Export** to a folder you choose. Nothing is uploaded.

## Everyday tasks

| Goal | Where to look |
| --- | --- |
| Combine PDFs | Merge / workspace |
| Shrink a large PDF | Compress |
| Password-protect | Protect / encrypt |
| Make a scan searchable | OCR / searchable PDF |
| Word/Excel → PDF | Convert (desktop builds with LibreOffice) |
| Images → PDF | Image tools |

## Keyboard

Desktop builds support common shortcuts (save, search, zoom, tool focus). Exact bindings are shown in the app’s help / command palette where available.

## Updates

```bash
document_studio --check-update
document_studio --update
```

Or use your package manager (`winget upgrade`, `brew upgrade --cask document-studio`, `apt` / new `.deb`). Details: [Updates](#/updates).
