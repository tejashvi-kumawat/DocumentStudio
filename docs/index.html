Download & install

Current release v1.0.3 · engines bundled · pick your platform

Windows

GUI installer · Start Menu · context menus

Download Setup.exe
  1. Run DocumentStudio-1.0.3-Setup.exe
  2. Finish the wizard (defaults are fine)
  3. Open Document Studio from Start

Portable zip on Releases · winget install DocumentStudio.DocumentStudio when listed

macOS

DMG → Applications · or Homebrew cask

Download .dmg
  1. Open the DMG · drag to Applications
  2. First open: right-click → Open if asked
  3. Spotlight: “Document Studio”
brew tap tejashvi-kumawat/tap
brew install --cask document-studio

Linux

Debian/Ubuntu .deb · app menu entry

Download .deb
  1. sudo apt install ./document-studio_1.0.3_amd64.deb
  2. Search Document Studio in Activities
  3. Or run document-studio
brew tap tejashvi-kumawat/tap
brew install document-studio

All assets: GitHub Releases v1.0.3 · Full install guide · document_studio --update

Features, one by one

Scroll the left column. The screenshot on the right stays pinned and swaps as each feature reaches the focus band. On phones, each feature keeps its own image underneath the text.

01 · Home

Your private document dashboard

Open PDFs, create blank files, convert images, and jump into All tools. Pinned and recent files stay on this device — the home screen literally says “everything stays on this device.”

  • Quick cards: Open · Create · Images to PDF · All tools
  • Drop zone + Browse for local files
  • Pinned gallery and Recent / Starred filters

02 · Tools hub

Every major action on one grid

The Tools screen surfaces Create PDF, Organize, PDF to images, Compress, Encrypt, and Scan as large cards — plus Create & Convert shortcuts for Office convert, fill form, and Sign PDF.

  • Search tools from the top of the grid
  • Open dropdown on each card for related actions
  • Same hub available from Home → All tools

03 · Catalog

Optimize · Sign · Edit · Create

The expanded Tools panel lists every specialized workflow with a short description — watermark, compress, batch, metadata, visual sign, stamps, certificate signature, fill form, edit text, compare PDFs, Office convert, and more.

  • Scrollable categorized list with red tool icons
  • Use when you know the job name but not the ribbon button

04 · Organize

Reorder, rotate, duplicate, reverse

Thumbnail grid for the whole document. Click to select, drag to reorder, rotate left/right, duplicate, delete, reverse order — then Apply.

  • Keyboard tip: Ctrl+Delete removes selected pages
  • Perfect for assembling packets before merge/export

05 · Merge

Stack multiple PDFs in order

Add files with + Add PDFs, keep the sequence you want, then Save or Save as. Protected sources show a lock until you unlock them.

  • Works from Tools or while a PDF is open
  • Keep originals — merge writes a new file

06 · Split

Slice a PDF with a live result list

Modes: every N pages, after pages, custom ranges, odd/even, or each page. The Result preview shows File 1, File 2, … before you commit. The open document stays intact.

07 · Extract

Pull pages into a new PDF

Scope: this page, selected, all, or a custom range. Optionally delete those pages from the open file after extract.

08 · Insert pages

Bring another PDF into this one

Insert every page of a second PDF after the chosen page — useful for appending lab reports, covers, or signed pages without a full merge dance.

09 · Crop

Trim margins with presets or a live box

Presets for full page, small margins, and wide margins, plus a draggable crop rectangle. Apply to this page, selected pages, all, or a range.

10 · Resize

LETTER · A4 · LEGAL media boxes

Sets MediaBox and CropBox to a target paper size. Content is not scaled or deleted — use when a printer or workflow expects a standard page size.

11 · Header & footer

Templates, variables, and position grid

Templates like Minimal page number, Page X of Y, Corporate, and Legal Bates. Drop tokens for page, date, file, title, or Bates numbers; save your own template.

12 · Page numbers

Style, prefix, start, sections

Number all pages or a from–to range. Choose style and prefix, set the starting number, and begin a new section when packets need restarted numbering.

13 · Encrypt

Passwords plus real permissions

Set a password to open and an optional owner password. Toggle allow printing, copying text, modifying, and annotating — then Encrypt. Remember the password; Document Studio cannot recover it.

14 · Watermark

Text or image overlays with full control

Text or Image modes, dynamic tokens, font/size/color, opacity, rotation presets, and a 3×3 position grid. Detect and remove existing watermarks before replacing.

15 · Digital sign

Certificates, .p12 import, validation

The Digital tab validates existing signatures, lets you draw signature fields, pick IDs from USB tokens / smart cards / NSS system stores, import .p12, or create a self-signed identity.

16 · Visual sign

Drawn signatures, initials, and stamps

Create signature and initials cards, then drag a box onto the page (or long-press drag). Resize and rotate with handles. Stamps cover Approved / date / custom marks.

17 · Edit & markup

Text, highlights, shapes, comments, links

Edit mode opens font controls, highlight/underline/strikethrough/squiggly, freehand + eraser, shapes, sticky notes, images, and links — with smart guides. Status shows “Saved in the PDF.”

18 · Insert scan

Camera capture or choose images

Frame a page with the camera, or choose existing photos/scans and insert them into the open PDF — great for appending receipts and paper forms.

19 · Pages toolkit

Extract, reorder, blank pages, and more

The Pages category also covers extract odd/even, reorder, reverse, duplicate, delete, rotate, add blank page, crop, resize, header & footer, page numbers, and insert scan — all searchable from the Tools panel.
