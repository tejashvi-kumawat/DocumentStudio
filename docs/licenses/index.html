Licenses

Document Studio’s own code is distributed under the license in the repository root (see the GitHub repo).

Desktop packages also bundle third-party engines. Each keeps its own terms:

  • qpdf and many PDF tools — their upstream licenses
  • Tesseract / tessdata — Apache-2.0 style upstream
  • LibreOffice — MPL-2.0 and extensive third-party notices
  • ffmpeg / NSS / OpenSSL — as shipped in the bundle

Release archives include a THIRD_PARTY_LICENSES directory. Read that folder for the copy that matches the bits you installed.

Corresponding source obligations for copyleft components are documented in the repository for redistributors.
