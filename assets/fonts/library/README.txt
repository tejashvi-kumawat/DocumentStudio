Bundled font library for Document Studio's Edit tools.

Every family here is licensed under the SIL Open Font License 1.1 or the
Apache License 2.0 (see "license" per family in index.json); both allow
bundling and embedding in documents. Sources: Google Fonts via Fontsource
(Latin subset, TrueType). Refresh with: python3 tool/fetch_fonts.py
